# Sprint Pulse branding

The logo is a sprint loop that runs straight into a heartbeat: the iteration keeps cycling, and the gadget reports its pulse. The dot at the end stands for the live auto-refresh.

## Files

| File | Use |
| --- | --- |
| `sprint-pulse-logo.svg` | Full logo (mark + wordmark) on light backgrounds; README header |
| `sprint-pulse-logo-dark.svg` | Full logo on dark backgrounds |
| `sprint-pulse-logo.png` | Full logo as a high-resolution PNG (light backgrounds) |
| `sprint-pulse-mark.svg` | Wide mark without the wordmark |
| `sprint-pulse-mark-dark.svg` | Wide mark for dark backgrounds |
| `sprint-pulse-icon.svg` | Compact square mark for icons |
| `sprint-pulse-icon-144.png` | Atlassian Marketplace app logo (144 × 144) |
| `sprint-pulse-icon-512.png` | Large square icon (512 × 512) |

Packaged in the plugin, under `my-jira-gadget/src/main/resources/images/`:

| File | Use |
| --- | --- |
| `pluginIcon.png` | 16 × 16 icon in Manage apps (`plugin-icon`) |
| `pluginLogo.png` | 72 × 72 logo in Manage apps (`plugin-logo`) |
| `thumbnail.png` | 120 × 60 thumbnail in the dashboard's Add gadget dialog: the square icon (`sprint-pulse-icon.svg`) centred, since Jira stretches thumbnails to 120 × 60 |
| `sprint-pulse-logo.svg` | Full logo shown in place of the "Sprint Health" title in the gadget |
